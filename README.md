## FAQ

**Is a security review a penetration test?**  
No. It is a written review, AI-assisted and human-approved. It is not a human penetration test, a compliance audit, or a certification. It cannot find every issue, and it is not a guarantee that a system is safe from attackers.

**What must I authorize?**  
Work is only on a site, API, or code you own or are authorized to have tested or cleaned. Submit and sign the authorization at the [request page](https://ghost77-agent.onrender.com/security/request), or email a written confirmation, before cleanup or review work starts. Default review testing is non-destructive and visitor-level. Cleanup requires access you provide, and only what you authorize is changed.

**When does work start?**  
Website Fix, Website Upkeep, and the FAQ chatbot start after payment and a confirmed scope (including your site URL, and your FAQ text for the chatbot). Hacked Site Cleanup and security reviews start only after payment and written authorization. If you pay by card first, the thank-you page will tell you what to send next.

**Can I cancel Website Upkeep or Chatbot Care?**  
Yes. Both are monthly subscriptions. Cancel any time from the Stripe receipt or by email. You will not be billed for later months after cancellation is processed.

**Do you guarantee the site will be safe?**  
No. No review or set of fixes can make a system completely secure. GhOsT77 will not claim that a site is hacker-proof or that every issue has been found.

**What is the Daily Hack Report?**  
A short, sourced weekday briefing of recent incidents from public sources (such as CISA, NVD, and established security newsrooms), with a “What to do” note for small-business site owners. It is not a complete threat feed and not a guarantee of security. Read it at [/reports](https://ghost77-security.onrender.com/reports) or the [RSS feed](https://ghost77-security.onrender.com/reports/feed.xml).

**How do I pay?**  
Website Fix, Hacked Site Cleanup, FAQ Chatbot Setup, FAQ Chatbot Care, and Website Upkeep use Stripe card checkout. Security reviews can be paid by card with the Stripe links above, or in USDC on Base through the authorization request. USDC is paid upfront, and only to the wallet listed in this README.

## Report a problem, contribute, or run the checks

- **Get it:** `git clone https://github.com/mxouiyavong-sys/ghost77-security.git`, or read the files on GitHub. Agents can fetch the raw JSON files directly.
- **Report a wrong price, link, or file:** open an [issue](https://github.com/mxouiyavong-sys/ghost77-security/issues). Security vulnerabilities go through [SECURITY.md](SECURITY.md), not public issues.
- **Contribute:** see [CONTRIBUTING.md](CONTRIBUTING.md). Changes land through pull requests to `main`.
- **Check the catalog:** with Python 3.9 or newer and nothing else installed, run:

```
python3 tools/validate_catalog.py
python3 -W error -m unittest discover -s tests -v
```

The validator checks the JSON files against [schemas/](schemas/), requires `https://` links, allows only the published payout wallet, and checks that prices agree between `pricing.json` and `services.json`. It reads local files only and makes no network requests.
